# Linux Guard Lite

## OS
Ubuntu Linux 22.04 / 24.04

## Language
Bash Shell Scripting

## Required packages
- bash
- sudo
- tar
- gzip
- cron
- at
- coreutils
- findutils
- iproute2
- iputils-ping
- passwd

## Modules
1. File Management
2. User Management
3. Permissions Management
4. Compression
5. Backup and Restore
6. Cron Scheduling
7. AT Scheduling
8. Network Configuration
9. System Administration
